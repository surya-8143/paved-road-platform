# Paved Road Platform

A portfolio internal developer platform for repeatable service delivery, infrastructure policy checks, keyless deployment and local Kubernetes admission control.

Status: foundation setup in progress. No cloud deployment or cost guarantee is claimed.

## Workspace

- `paved-road-platform`: shared workflows, infrastructure modules, policies and documentation.
- `paved-road-template`: application template and service-level workflows.
- `paved-road-demo-service`: generated consumer used to demonstrate the platform.

All three repositories are local under `D:\CLOUD`. No GitHub repositories have been published yet.

See [project status and acceptance criteria](docs/PROJECT_STATUS.md).
